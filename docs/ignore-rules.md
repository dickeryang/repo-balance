# 忽略规则（Ignore Rules）

> 本文档描述 `.repobalance-ignore` 的语法、内置默认项与「编辑器 / CLI」的行为口径，
> 对应路线图关键缺口「忽略规则 GUI 编辑器」的补齐（2026-10-23 落地）。
> 实现见 `crates/rb-core/src/ignore.rs`，界面见设置页「忽略规则」。

## 一、定位

构建产物、依赖缓存、第三方代码不该进入健康度结论——它们的体积与内容都是噪音。
忽略规则就是这份「不参与体检的清单」：

- **随仓库走**：规则文件放在仓库根目录（`.repobalance-ignore`），与 `.gitignore` 同理，换机器、换同事都一致；
- **采集层生效**：被忽略的路径不进入任何切片（工作区文件 / 历史 blob / 文件内容 / 依赖清单），因此所有检查器都看不到它们，不是「扫出来再过滤」；
- **可否定**：内置默认忽略的目录可以用 `!` 单独放行。

## 二、语法

gitignore 风格子集，按行声明：

| 语法 | 含义 | 示例 |
|---|---|---|
| `#` 开头 | 注释，整行跳过 | `# 构建产物` |
| 空行 | 跳过 | — |
| `!` 前缀 | **否定**：取消忽略（最后匹配胜出） | `!target/keep.bin` |
| 前导 `/` | 锚定到仓库根，不匹配子目录同名路径 | `/vendor` |
| 尾随 `/` | 仅匹配目录（及该目录下所有文件） | `node_modules/` |
| `*` | 匹配除 `/` 外的任意字符 | `*.bin` |
| `?` | 匹配单个非 `/` 字符 | `?.txt` |
| `**` | 匹配任意层级路径段 | `src/**/test.txt` |

**求值顺序**：规则按声明顺序求值，**最后匹配的规则决定结果**（与 gitignore 一致）。
所以 `*.log` + `!keep.log` = 忽略所有日志但保留 `keep.log`；把 `*.log` 再写一遍则 `keep.log` 又被忽略。

## 三、内置默认忽略

`target/`、`node_modules/`、`dist/`、`build/`、`out/`、`.venv/`、`venv/`、`__pycache__/`、
`.pytest_cache/`、`.gradle/`、`.next/`、`.nuxt/`、`coverage/`（共 13 条）。

- 这些默认项**在用户规则之前**注入，因此用户规则声明在后、优先级更高；
- 需要放行其中某个文件时，用 `!` 否定即可（如 `!target/keep.bin`）；
- 默认项**不写进** `.repobalance-ignore` 文件，避免污染用户的规则清单。

## 四、使用方式

### 图形界面（设置页 → 忽略规则）

1. **选仓库**：忽略规则属于具体仓库，未选仓库时编辑器只读禁用；「选择仓库…」复用系统目录选择对话框。
2. **编辑**：文本域直接读写仓库根目录的 `.repobalance-ignore`（文件不存在时以空内容开始，保存即创建）。
3. **试算**：把**尚未保存**的内容交给后端求值（不落盘），返回：
   - 工作区文件总数、被忽略文件数、占比、被忽略文件总字节数（**精确值**，非采样外推）；
   - 被忽略路径样本（最多 20 个，超出时如实标注「仅显示前 20 个」）；
   - 规则静态检查结论（见下）。
4. **保存**：原子写（临时文件 + rename），成功即回写「已保存内容」用于脏标记。

> 保存是本应用**唯一写入被检查仓库**的操作：只写根目录这一个文件，
> 不触碰 git 对象库、提交历史与工作区其它内容。

### 命令行（只读校验）

```bash
rb ignore <path>
```

打印用户规则条数 + 内置默认条数，并列出「写了却不会生效」的规则；
存在可疑规则时退出码为 1（可放进 CI 或 pre-commit），仓库未配置忽略规则时退出码为 0。

## 五、行为口径

| 口径 | 说明 |
|---|---|
| 试算口径 | 与扫描完全一致：内置默认 + 用户规则、最后匹配胜出（`parse_with_defaults` 与扫描入口 `load_from` 同源实现，有测试锁定一致性） |
| 试算是否落盘 | **不落盘**；只有显式点击「保存到仓库」才写入 |
| 影响面统计 | 文件数 / 占比 / 字节数均为精确值（遍历工作区文件元数据），不做采样外推 |
| 样本上限 | 20 条，超出置 `truncated` 并在界面如实标注 |
| 静态检查（lint） | 只提示、不阻止保存：空模式（`/`、`!` 等无有效路径段，永不匹配）、反斜杠分隔（引擎按 `/` 分段）、规则重复（前面那条无效果） |
| 写入方式 | 原子写（`.repobalance-ignore.tmp` → rename），失败时清理临时文件 |
| 作用范围 | 采集层过滤：工作区文件、历史 blob、文件内容、依赖清单；分支拓扑不受影响 |

## 六、常见陷阱

| 现象 | 原因与写法 |
|---|---|
| 规则写了却不生效 | 用了反斜杠（`src\dist`）——改用 `src/dist`；或模式只有 `/`、`!`，没有有效路径段 |
| 想忽略目录却没忽略 | 目录模式要尾随 `/`（`node_modules/` 匹配目录下所有文件；`node_modules` 只匹配同名文件本身） |
| 想只忽略根目录的目录 | 加前导 `/` 锚定（`/build/` 不匹配 `sub/build/x.o`） |
| `!` 放行没生效 | 否定规则必须声明在对应的忽略规则**之后**（最后匹配胜出） |
| 默认忽略的目录被误伤 | 用 `!` 明确放行，如 `!target/keep.bin` |
